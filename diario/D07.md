# D07 — Síntese

**Data:** _(a preencher)_
**Pergunta do dia:** O que dá para construir, o que é filosofia, e qual o veredito honesto sobre "agente próximo de mente humana"?

## Objetivo

Fechar a semana integrando as cinco dimensões (verificação, intenção,
intensidade, emoção, identidade) numa arquitetura de referência — e separar
com clareza o que é engenharia resolvida, o que é engenharia aberta, e o que
é questão filosófica que a engenharia não resolve.

## Estrutura da síntese (a preencher)

1. **A arquitetura mínima** — o esqueleto que um agente precisa ter para
   satisfazer as 4 propriedades da definição de trabalho (ver PROTOCOLO.md).
2. **O que já dá para construir hoje** — com o que existe de LLM + ferramentas
   + memória + drive states.
3. **O que é aberto** — stake próprio, fidelidade do processo, integração
   de emoção sem corpo.
4. **O que é filosofia** — qualia, o problema difícil, o teste de Turing como
   armadilha.
5. **Veredito honesto** — a imitação conta? Onde a imitação para de ser
   imitação.
