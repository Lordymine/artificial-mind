# D05 — Emoção fenomenal

**Data:** _(a preencher)_
**Pergunta do dia:** Dá para uma máquina *sentir* — ou tudo que podemos construir é correlato sem qualia?

## Objetivo

Enfrentar o problema difícil (Chalmers) sem fingir que ele é resolvido, mas
também sem usá-lo como desculpa para não construir o resto. Mapear as posições:
funcionalismo, ilusionismo, panpsiquismo — e o que cada uma implica para o projeto.

## Leituras (a aprofundar)

- Nagel — *What Is It Like to Be a Bat?* (1974): existe um "como é ser" o
  morcego, e esse fato é inacessível à terceira pessoa.
- Chalmers — *The Conscious Mind* (1996): o problema difícil; a tese de que
  funcionalismo não explica qualia.
- Dennett — *Consciousness Explained* (1991) / *The Unimagined Preposterousness*:
  qualia como confusão conceitual — a posição ilusionista.
- Tononi — *Integrated Information Theory (IIT)*: consciência = Φ integrado.
  Dá um critério mensurável (e polêmico) de "quanto um sistema sente".
